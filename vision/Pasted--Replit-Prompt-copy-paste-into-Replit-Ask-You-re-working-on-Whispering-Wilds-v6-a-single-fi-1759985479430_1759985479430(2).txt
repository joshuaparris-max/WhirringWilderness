Built-in test command for smoke tests

Your tasks:

Add Playwright (Node) with TypeScript:

npx playwright install --with-deps

Non-breaking QA test suite
Create these Playwright specs under tests/ and make them pass without changing public behaviours, function signatures, save keys, or extension chaining:

tutorial.spec.ts
Walk the tutorial end-to-end:

look → take key → inv → map → n → quests

Assert: UI prints expected lines; Rusty Key in inv; minimap shows @ moved; “Tutorial complete” banner appears.

movement_combat_guard.spec.ts

Force an encounter (or hunt) and assert moving is blocked during combat; after victory you can move.

Assert attack 3 stops when enemy dies (partial repeat honoured).

gathering_cooldown.spec.ts

forage, then assert cooldown message; perform two non-gather actions (look, stats); forage succeeds again.

rest should reset gather cooldown (message shows).

crafting_and_use.spec.ts

Give player herb x3 via console or helper; craft lesser potion works; use potion heals expected amount.

craft bandage from fiber; use bandage heals correct amount.

quests.spec.ts

Caretaker: accept Heal the Grove, add herbs, turnin → gold/XP awarded and quest state becomes turned_in.

Quests panel updates progress on each step.

panels_minimap.spec.ts

Move between rooms; assert side panels update quietly (map/quests/inv); toggling minimap preference persists in localStorage across reload.

clickable_text.spec.ts

Click a clickable item/NPC name; the input box autofills; pressing send runs the right command.

save_load.spec.ts

Set a non-default state (gold, mats, room); save; reload the page; load; assert state restored (including new mats if v6 added some).

fuzz_console.spec.ts

Generate 200 random/invalid commands (e.g., “forag”, “attack caretaker”, “take sanctum”); assert:

no JS/Py errors in console,

game prints a friendly error (e.g., “Unknown command” / “You can’t take Caretaker”),

state doesn’t corrupt.

golden_transcript.spec.ts

Run a fixed transcript (the one the user shared) verbatim. Because RNG is seeded, compare output lines against a stored golden file but ignore timestamps and trailing whitespace. Update the golden only on intentional changes.

Cooldown not resetting on rest → ensure reset + test.

Keep save format and ext chain intact (ext_handle_command must keep delegating in order). Migrations must be additive only.
